# BananGPT 🍌 (многопользовательская версия)

Telegram-бот поверх личного веб-аккаунта Gemini (куки). Рассчитан на ~10 человек: админ видит всех,
одобряет заявки, банит, задаёт лимиты.

## Файлы (все в корень репозитория)
| Файл | Зачем |
|---|---|
| `bot.py` | сам бот |
| `textfmt.py` | очистка текста от Markdown/LaTeX (знаки умножения остаются) |
| `chartbox.py` | изолированное построение графиков |
| `docgen.py` | настоящие PDF и DOCX |
| `store.py`, `users.py` | база (SQLite / Postgres), пользователи, лимиты |
| `requirements.txt` | зависимости |
| `Dockerfile`, `.dockerignore` | запуск в Docker не от root (по желанию) |
| `Procfile`, `.gitignore`, `README.md`, `test_bot.py` | вспомогательные |

## Переменные окружения
| Переменная | Нужна | Значение |
|---|---|---|
| `TELEGRAM_TOKEN` | да | токен от @BotFather |
| `GEMINI_SECURE_1PSID` / `GEMINI_SECURE_1PSIDTS` | да | куки из Firefox (приватное окно, закрыть без выхода из аккаунта) |
| `ALLOWED_IDS` | да | твой Telegram ID (стартовый пользователь, он же админ) |
| `ADMIN_IDS` | нет | админы через запятую; если пусто — наименьший ID из `ALLOWED_IDS` |
| `DATABASE_URL` | **очень желательно** | Postgres (см. ниже). Без него всё стирается при каждом рестарте Render |
| `MAX_USERS` | нет | сколько активных пользователей (10) |
| `DAILY_LIMIT` | нет | запросов в день на человека (30), 0 = без лимита |
| `TZ_OFFSET_HOURS` | нет | сдвиг для «дня» (3 = Москва) |
| `ALLOW_REQUESTS` | нет | `0` — чужие не могут подавать заявки |
| `GEMINI_CONCURRENCY` | нет | сколько запросов к Gemini одновременно (2) |
| `HEALTH_INTERVAL` | нет | проверка Gemini раз в N секунд (3600), 0 = выкл. |
| `DEFAULT_MODEL`, `MODEL_TIMEOUT`, `REQUEST_TIMEOUT`, `BOT_THREADS`, `LOG_LEVEL` | нет | см. комментарии в `bot.py` |
| `GEMINI_COOKIE_PATH` | нет | `/tmp/gemini_webapi` |

## Бесплатная база (Neon)
1. neon.tech → Sign up → Create project (регион поближе, без карты).
2. На странице проекта нажми **Connect**, скопируй строку `postgresql://…?sslmode=require`.
3. В Render → Environment добавь `DATABASE_URL` = эта строка. Таблицы создаются сами.

## Доступ только по твоему одобрению
Незнакомый человек пишет боту → бот отвечает «заявка отправлена» → тебе приходит сообщение с кнопками
**Одобрить / Отклонить / Открыть профиль**. Пока не одобришь, доступа нет. Отклонённый попадает в бан и боту больше не пишет.

## Админ-панель (кнопки)
Кнопка **«👑 Админ-панель»** внизу (или `/admin`) → списки «Все / Заявки / Активные / Баны» → нажми на человека — откроется
его карточка (имя, @ник, ID, статус, когда зашёл, сколько запросов сегодня и всего, модель, режим) с кнопками:
**Одобрить · Отклонить · Мут · Бан · Лимит · Написать · Удалить · Снять мут · Разбанить**.
Мут и бан выбираются на время: 15 мин / 1 час / 6 часов / 1 день / 7 дней / 30 дней / навсегда.
Замученный и забаненный на время получают сообщение «ещё N»; когда срок выйдет, доступ возвращается сам.
Забаненный навсегда боту не отвечает вообще. Админа замутить и забанить нельзя.

## Команды
Пользователь: `/mode`, `/model`, `/models`, `/me`, `/new`, `/ping`, `/status`, `/help`, `/myid`.
Админ (то же самое без кнопок): `/admin`, `/users`, `/user <id|@ник>`, `/adduser <id>`, `/mute <id|@ник> <30м|2ч|1д|1н|навсегда> [причина]`,
`/unmute`, `/ban <id|@ник> [время] [причина]`, `/unban`, `/removeuser`, `/limit <id|@ник> <число|0|default>`,
`/stats`, `/cookies`, `/broadcast <текст>`.

## Render
**Вариант А — Python:** Language Python 3, Build `pip install -r requirements.txt`, Start `python bot.py`,
переменная `PYTHON_VERSION` = `3.12.3`. (Render игнорирует Procfile.)
**Вариант Б — Docker (рекомендую):** Language **Docker**, Build/Start команды не нужны. Python 3.12 и запуск не от root
зашиты в `Dockerfile`.
Health Check Path: `/`. Бесплатный сервис засыпает без входящих запросов — добавь монитор UptimeRobot на адрес сервиса.

## Тесты
`python test_bot.py` — 91 тест на заглушках (нужны только numpy и matplotlib). Живые Gemini, Telegram и Postgres они не проверяют.

## Безопасность графиков
AST-фильтр + отдельный процесс с пустым окружением, таймаутом и лимитами. Это защита в глубину, а не настоящая песочница;
в Docker под отдельным пользователем она заметно надёжнее.
