# BananGPT 🍌 (многопользовательская версия)

Telegram-бот поверх личного веб-аккаунта Gemini (куки). Рассчитан на ~10 человек: админ видит всех,
одобряет заявки, банит, задаёт лимиты.

## Файлы (все в корень репозитория)
| Файл | Зачем |
|---|---|
| `bot.py` | сам бот |
| `textfmt.py` | очистка текста от Markdown/LaTeX (знаки умножения остаются) |
| `chartbox.py` | изолированное построение графиков |
| `docgen.py` | настоящие PDF и DOCX |
| `store.py`, `users.py` | база (SQLite / Postgres), пользователи, лимиты |
| `localmode.py` | локальный запуск на ПК: `.env`, папка данных, лог-файл, защита от двойного запуска, бэкап |
| `run.bat`, `.env.example` | запуск на Windows одним файлом |
| `migrate_to_postgres.py` | перенос локальной SQLite-базы в Postgres (Render) |
| `requirements.txt` | зависимости |
| `Dockerfile`, `.dockerignore` | запуск в Docker не от root (по желанию) |
| `Procfile`, `.gitignore`, `README.md`, `test_bot.py` | вспомогательные |

## Переменные окружения
| Переменная | Нужна | Значение |
|---|---|---|
| `TELEGRAM_TOKEN` | да | токен от @BotFather |
| `GEMINI_SECURE_1PSID` / `GEMINI_SECURE_1PSIDTS` | да | куки из Firefox (приватное окно, закрыть без выхода из аккаунта) |
| `ALLOWED_IDS` | да | твой Telegram ID (стартовый пользователь, он же админ) |
| `ADMIN_IDS` | нет | админы через запятую; если пусто — наименьший ID из `ALLOWED_IDS` |
| `DATABASE_URL` | **очень желательно** | Postgres (см. ниже). Без него всё стирается при каждом рестарте Render |
| `MAX_USERS` | нет | сколько активных пользователей (10) |
| `DAILY_LIMIT` | нет | запросов в день на человека (30), 0 = без лимита |
| `TZ_OFFSET_HOURS` | нет | сдвиг для «дня» (3 = Москва) |
| `ALLOW_REQUESTS` | нет | `0` — чужие не могут подавать заявки |
| `GEMINI_CONCURRENCY` | нет | сколько запросов к Gemini одновременно (2) |
| `HEALTH_INTERVAL` | нет | проверка Gemini раз в N секунд (3600), 0 = выкл. |
| `DEFAULT_MODEL`, `MODEL_TIMEOUT`, `REQUEST_TIMEOUT`, `BOT_THREADS`, `LOG_LEVEL` | нет | см. комментарии в `bot.py` |
| `GEMINI_COOKIE_PATH` | нет | `/tmp/gemini_webapi` (локально ставится сам: `DATA_DIR\\gemini_cookies`) |
| `USE_POLLING` | нет | `1` — локальный режим на ПК (без health-сервера и самопинга). На Render не задавать |
| `DATA_DIR` | нет | папка всех локальных данных; пусто + `USE_POLLING=1` → папка `data` рядом с ботом. На Render не задавать |
| `GEMINI_COOKIES_FILE` / `GEMINI_COOKIE_HEADER` | нет | полный набор кук браузера (строка `Cookie`), если двух `1PSID`/`1PSIDTS` Google не хватает (редирект на `ServiceLogin`). Файл или сама строка; в логе печатаются только имена кук |
| `HEARTBEAT_URL`, `HEARTBEAT_INTERVAL` | нет | адрес проверки (healthchecks.io), который бот пингует раз в 300 с; нет пульса — сервис пришлёт уведомление |
| `BACKUP_EXTRA_DIR` | нет | вторая папка для копий базы (например, облачная); локально, последние 7 |
| `COOKIE_KEY` | нет | свой ключ шифрования сохранённых кук (по умолчанию берётся из токена бота) |
| `COOKIE_SAVE_INTERVAL` | нет | как часто сохранять куки в базу, секунд (300), 0 = выкл. |

## Локальный запуск на Windows
Бот и на Render работает через polling (не webhook); `USE_POLLING=1` лишь включает локальный режим.
1. Установи Python 3.10+ (python.org, галка **Add python to PATH**).
2. Скопируй `.env.example` → `.env`, впиши `TELEGRAM_TOKEN`, `GEMINI_SECURE_1PSID`, `GEMINI_SECURE_1PSIDTS`, `ALLOWED_IDS`.
   `DATABASE_URL` оставь пустым → SQLite в `DATA_DIR\bananbot.db`. (Или впиши ту же строку Neon, что на Render — тогда данные общие и переносить ничего не надо.)
3. Запусти `run.bat`: создаст venv, поставит зависимости, запустит бота; при падении перезапустит через 10 с. Остановка — Ctrl+C.
4. В `DATA_DIR`: `bananbot.db` (пользователи, диалоги, зашифрованные куки), `work\` (файлы), `gemini_cookies\`, `bot.log` (ротация 5×5 МБ), `backup\` (копия базы раз в день при старте, последние 7).
5. Куки: Firefox/Chrome → приватное окно → gemini.google.com → войти → F12 → Storage/Application → Cookies → скопировать `__Secure-1PSID` и `__Secure-1PSIDTS` в `.env` → окно закрыть без выхода из аккаунта.
   Когда сессия истекла, админ получает в Telegram сообщение «🚨 Gemini не принимает куки» с инструкцией; обнови `.env` и перезапусти `run.bat`.
6. Два экземпляра с одним токеном конфликтуют: на ПК второй `run.bat` откажется стартовать, а если параллельно оживёт Render, админ получит «два экземпляра бота (409)».

**Без окна терминала.** `start_hidden.vbs` запускает `run.bat` скрыто (автозапуск Windows использует его), `stop.bat` останавливает бота
(в том числе скрытого). О том, что бот жив, говорит Telegram, `bot.log` в папке данных и пульс (`HEARTBEAT_URL`).
Ярлык автозапуска: цель `wscript.exe "C:\\banangpt\\start_hidden.vbs"`.

**Куки на ПК.** Двух `1PSID`/`1PSIDTS` Google может не хватить (в логе редирект на `ServiceLogin`, ответы гостевые): тогда положи
в `DATA_DIR\\gemini_cookies.txt` всю строку `Cookie` из F12 → Сеть → запрос `gemini.google.com/app` и впиши в `.env` `GEMINI_COOKIES_FILE=<путь>`.
Бот сам сохраняет обновлённые куки в базу. Файл содержит всю сессию Google — закрой его от других пользователей ПК:
`icacls C:\\bananagpt-data\\gemini_cookies.txt /inheritance:r /grant:r "${env:USERNAME}:F"`. Пока сессия слетела, обычные пользователи
получают «сервис временно недоступен», а админ — уведомление. `HEARTBEAT_URL` (healthchecks.io) предупредит, если бот совсем замолчал.

**Возврат на Render:** останови `run.bat` → при желании `venv\Scripts\python migrate_to_postgres.py --from <DATA_DIR>\bananbot.db --to "<DATABASE_URL с Render>"`
(сначала без `--apply` — пробный прогон; куки не переносятся) → обнови куки в Render и включи сервис.

## Бесплатная база (Neon)
1. neon.tech → Sign up → Create project (регион поближе, без карты).
2. На странице проекта нажми **Connect**, скопируй строку `postgresql://…?sslmode=require`.
3. В Render → Environment добавь `DATABASE_URL` = эта строка. Таблицы создаются сами.

## Куки сохраняются сами
Gemini обновляет куки раз в несколько минут, а в Render остаётся старая копия — поэтому после рестарта бот становился «гостем».
Теперь бот раз в 5 минут, при подключении и при остановке контейнера кладёт свежие куки в базу (**нужен `DATABASE_URL`**)
в зашифрованном виде, а при запуске берёт их оттуда. Если ты сам вставил новые куки в Render, бот это замечает и берёт их.
Если куки из базы не подошли, он пробует куки из Render. В гостевом режиме ничего не сохраняется, чтобы не затереть хорошие.
Состояние видно в админ-панели → «🔑 Куки Gemini» (или `/cookies`). Если там «не удалось прочитать 1PSIDTS из клиента»,
значит, эта версия gemini-webapi хранит куки иначе — пришли этот текст разработчику бота.
Ключ шифрования берётся из токена бота: если перевыпустишь токен, сохранённые куки не расшифруются, и бот возьмёт куки из Render.

## Доступ только по твоему одобрению
Незнакомый человек пишет боту → бот отвечает «заявка отправлена» → тебе приходит сообщение с кнопками
**Одобрить / Отклонить / Открыть профиль**. Пока не одобришь, доступа нет. Отклонённый попадает в бан и боту больше не пишет.

## Админ-панель (кнопки)
Кнопка **«👑 Админ-панель»** внизу (или `/admin`) → списки «Все / Заявки / Активные / Баны» → нажми на человека — откроется
его карточка (имя, @ник, ID, статус, когда зашёл, сколько запросов сегодня и всего, модель, режим) с кнопками:
**Одобрить · Отклонить · Мут · Бан · Лимит · Написать · Удалить · Снять мут · Разбанить**.
Мут и бан выбираются на время: 15 мин / 1 час / 6 часов / 1 день / 7 дней / 30 дней / навсегда.
Замученный и забаненный на время получают сообщение «ещё N»; когда срок выйдет, доступ возвращается сам.
Забаненный навсегда боту не отвечает вообще. Админа замутить и забанить нельзя.

## Команды
Пользователь: `/mode`, `/model`, `/models`, `/me`, `/new`, `/ping`, `/status`, `/help`, `/myid`.
Админ (то же самое без кнопок): `/admin`, `/users`, `/user <id|@ник>`, `/adduser <id>`, `/mute <id|@ник> <30м|2ч|1д|1н|навсегда> [причина]`,
`/unmute`, `/ban <id|@ник> [время] [причина]`, `/unban`, `/removeuser`, `/limit <id|@ник> <число|0|default>`,
`/stats`, `/cookies`, `/broadcast <текст>`.

## Render
**Вариант А — Python:** Language Python 3, Build `pip install -r requirements.txt`, Start `python bot.py`,
переменная `PYTHON_VERSION` = `3.12.3`. (Render игнорирует Procfile.)
**Вариант Б — Docker (рекомендую):** Language **Docker**, Build/Start команды не нужны. Python 3.12 и запуск не от root
зашиты в `Dockerfile`.
Health Check Path: `/`. Бесплатный сервис засыпает без входящих запросов — добавь монитор UptimeRobot на адрес сервиса.

## Тесты
`python "test bot.py"` — 113 тестов на заглушках (7 про графики/PDF пропускаются, если не установлен matplotlib) и `python test_localmode.py`
(локальный режим, миграция, куки). Живые Gemini, Telegram и Postgres они не проверяют.

## Безопасность графиков
AST-фильтр + отдельный процесс с пустым окружением, таймаутом и лимитами. Это защита в глубину, а не настоящая песочница;
в Docker под отдельным пользователем она заметно надёжнее.
